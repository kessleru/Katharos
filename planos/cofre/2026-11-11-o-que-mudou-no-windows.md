# O que mudou no Windows (novembro de 2026)

Fonte: [recursos obsoletos e removidos](https://learn.microsoft.com/windows/whats-new/deprecated-features).

- **WMIC** removido do Windows 11 24H2 em diante (não é mais recurso opcional). O Katharos não usa; um teste garante.
- **PowerShell 2.0** obsoleto, sai numa versão próxima. O Katharos usa o Windows PowerShell 5.1 pelo caminho completo.
- **Histórico de Localização** removido. Nenhum item mexe nele.
- **Mapas, 3D Viewer, Paint 3D** saíram da Loja: os itens de apps não precisam mais deles.

Rotina: ler antes de cada versão (passo do "Publicar uma versão" no CONTRIBUTING).
